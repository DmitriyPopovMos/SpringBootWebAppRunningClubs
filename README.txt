

SpringBootWebAppRunningClubs
Приложение по управлению Беговыми клубами и событиями в мире спорта>.


♣ ФУНКЦИОНАЛ ♣

1. Регистрация на сайте
2. Вход для авторизованных пользователей с возможностью управления Клубами и Событиями
    • Получение списка всех Клубов и списка всех Событий
    • Добавление нового Клуба и нового События
    • Редактирование Клуба и События
    • Удаление Клуба и События
3. Для неавторизованных пользователей имеется только возможность просмотра Списка Клубов и списка Событий без возможности управления ими.

4. В проекте используется SpringSecurity+BCrypt+Thymeleaf.extras+Validation
    Организована Валидация и Верификация данных пользователей с подключением Spring Security
    • Сохранение данных авторизованных пользователей (username, email, password)
    • Шифрование пароля пользователя (BCrypt) и сохранение в БД
    • Вход в систему для авторизованных пользователей (username, password)
    • При регистрации нового пользователя Организована проверка на совпадение данных с уже существующими пользователями в БД.
    • Организована проверка данных при входе в систему с учетными данными пользователя.
    • Предусмотрен выход пользователя из системы (Logout)

5. Имеется Фильтр поиска Клуба по слову или по части слова из названия клуба.

6. В проекте используется БД PostgreSQL (установлена сортировка в порядке возрастания по полю "id").

7. В проекте используется Bootstrap+Thymeleaf+CSS

♦ ТЕХНИЧЕСКАЯ ЧАСТЬ ♦

1. Получать, Добавлять, Редактировать, Удалять Клубы (Club)

• Получение общего количества Клубов в БД (CRUD)
GET /clubs
Параметры: title, photoUrl.
Выводит список всех Клубов в БД.


• Получение Деталей (подробнее) Клуба в БД (CRUD)
GET /clubs/{id}
Параметры: title, photoUrl, content.
Выводит более подробные данные о Клубе в БД.


• Добавление нового Клуба (CRUD):
GET /clubs/new
POST /clubs/save
Параметры: title, photoUrl, content.
Увеличивает количество Клубов в БД.


• Редактирование Клуба (CRUD):
GET /clubs/update/{id}
POST /clubs/update
Параметры: title, photoUrl, content.
Вносит изменения в существующие данные в БД


• Удаление Клуба (CRUD):
GET /clubs/delete/{id}
Параметры: title, photoUrl, content.
Удаляет Клуб из БД


---------------------------------------------

2. Получать, Добавлять, Редактировать, Удалять События (Event)

• Получение общего количества Событий в БД (CRUD)
GET /events
Параметры: name, photoUrl.
Выводит список всех Событий в БД.

• Получение Деталей (подробнее) о Событии в БД (CRUD)
GET /events/{id}
Параметры: name, photoUrl, createdOn, type, club.createdBy.
Выводит более подробные данные о Событии в БД.

• Добавление нового События (CRUD):
GET /events/new/{id}
POST /events/{id}
Параметры: name, type, photoUrl, startTime, endTime.
Увеличивает количество Событий в БД.


• Редактирование События (CRUD):
GET /events/update/{id}
POST /events/update/{id}
Параметры: name, type, photoUrl, startTime, endTime.
Вносит изменения в существующие данные в БД


• Удаление События (CRUD):
GET /events/delete/{id}
Параметры: name, type, photoUrl, startTime, endTime.
Удаляет Событие из БД
